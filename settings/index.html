2. Amazon Associates & live product data
Start here — live Amazon data is optional.
  1. Create an Amazon Associates account for the marketplace you use.
  2. Add your website/app and complete the Associates profile.
  3. Amazon gives you a marketplace-specific Partner Tag / Store ID. You can save it below immediately.
  4. Your Associates account must become Approved before Creators API access is available.
  5. For Product Advertising API access through Creators API, Amazon currently requires at least 10 qualifying sales in the last 30 days.
  6. When eligible: open Associates Central → Tools → Creators API, create an application and create credentials.
  7. Copy the Credential ID and Credential Secret into Homey. Amazon only shows the secret when it is created.
  8. Enable live data below and press Save & test Amazon connection.

Not eligible yet? Leave live data disabled. Shopping lists, parcel tracking and Homey Flows still work normally.
