Shopping Companion lagrar dina inköpslistor, bevakade produkter och kolliuppgifter på din egen Homey Pro. Använd informationen i Homey och Flow för att reagera på prisändringar, lagersaldo och leveranshändelser.

Valfri live-data från Amazon kan aktiveras med användarens egna Amazon Creators API-uppgifter. Köp genomförs alltid manuellt utanför Homey; Shopping Companion kan aldrig skapa beställningar eller hantera checkout, betalningar eller leveransadresser.
