Setup & support

Everything you need to get Shopping Companion running on your own Homey Pro.

Start here

You do not need an Amazon API account to use Shopping Companion. Shopping lists, manual product links, parcel data and Homey Flows work without Amazon Creators API.

Basic setup

1. Install Shopping Companion on Homey Pro. 2. Open the app settings. 3. Select your Amazon marketplace/country. 4. Save. You can now use lists, parcel events and Homey Flows.

Optional: Amazon live product data

Live search, current price and stock data require your own Amazon Associates account and Creators API access.

1. Create an Amazon Associates account for your marketplace. 2. Add your website/app and complete the Associates profile. 3. Save the Partner Tag / Store ID Amazon gives you. 4. Wait until the Associates account is approved. 5. Amazon currently requires at least 10 qualifying sales in the last 30 days for Product Advertising API access through Creators API. 6. Open Associates Central → Tools → Creators API. 7. Create an application and generate credentials. 8. Copy Credential ID and Credential Secret into Shopping Companion on Homey. 9. Enable live data and press “Save & test Amazon connection”.

I only have a Partner Tag

That is normal for a new Associates account. Save the Partner Tag in Homey, leave live data disabled and continue using the basic features.

I cannot create API credentials

Your Associates account is probably not eligible yet. Check the Creators API page in Associates Central. Requirements are controlled by Amazon and may change.

Which Credential Version?

Use the version shown for your region in Shopping Companion. For Sweden and most European marketplaces this is currently 3.2.

Multiple countries

Partner Tags are marketplace-specific. Configure the correct tag for each Amazon marketplace you use.

Where are credentials stored?

On your own Homey. Shopping Companion does not send your Creators API credentials to Creson.

Can the app buy anything?

No. Shopping Companion has no checkout, cart, payment, address-change or order-placement capability.

Important security note

Never enter your normal Amazon shopping password in Shopping Companion. Credential Secret is a separate Creators API credential. Shopping Companion never stores an authenticated Amazon browser session.
